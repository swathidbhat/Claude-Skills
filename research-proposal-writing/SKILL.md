# Research proposal & writing

Use this whenever building or revising a research proposal (or the research-writing spine that feeds it). Work phase by phase; do not skip earlier foundations when a later section is weak.

Source pattern: a 50-step proposal checklist (topic → submit). Adapt depth to the field, degree level, and supervisor requirements — do not invent ethics approvals, sample sizes, or citations.

## Copy-pasteable fix / run prompt

```
Build or revise my research proposal using this 50-step path. For each step: do the work or mark DONE / NEEDS INPUT / N/A with a one-line reason. Never invent sources, sample sizes, ethics approval, or results. Ask me only when a fact only I know is required.

BEFORE YOU START (1–8): topic, background reading, problem, gap, questions, objectives, rationale, key concepts.
RESEARCH PLANNING (9–13): literature review + organize it, theoretical framework, conceptual framework, research approach.
RESEARCH DESIGN (14–37): design, methodology, population, sampling strategy, sample size, sampling technique, inclusion/exclusion, data collection methods & instruments, validity, reliability, pilot plan, revise instruments, collection procedures, analysis plan, statistical tests/techniques, ethics, consent forms, confidentiality/anonymity, limitations, scope/delimitations, timeline, budget.
PROPOSAL WRITING (38–46): introduction, problem statement, questions & objectives, literature review, methodology, ethical considerations, expected outcomes, significance, references.
REVIEW & REVISION (47–49): citations/formatting, edit/proofread, supervisor feedback + revise.
SUBMISSION (50): finalize and submit.

Deliver: (1) status table by phase, (2) draft sections I asked for, (3) open questions for me / my supervisor.
```

## Assistant recipe

### 1. Before you start (steps 1–8)
1. Choose a research topic  
2. Conduct background reading  
3. Identify the research problem  
4. Define the research gap  
5. Formulate research questions  
6. Develop research objectives  
7. Establish research rationale  
8. Define key concepts  

### 2. Research planning (steps 9–13)
9. Review relevant literature  
10. Organize the literature review  
11. Identify theoretical framework  
12. Develop conceptual framework  
13. Select research approach  

### 3. Research design (steps 14–37)
14. Choose research design  
15. Select research methodology  
16. Define study population  
17. Determine sampling strategy  
18. Calculate sample size  
19. Select sampling technique  
20. Define inclusion criteria  
21. Define exclusion criteria  
22. Choose data collection methods  
23. Develop data collection instruments  
24. Ensure instrument validity  
25. Ensure instrument reliability  
26. Plan pilot testing  
27. Revise research instruments  
28. Plan data collection procedures  
29. Plan data analysis  
30. Select statistical tests/techniques  
31. Address ethical considerations  
32. Prepare informed consent forms  
33. Ensure confidentiality/anonymity  
34. Identify potential limitations  
35. Define scope and delimitations  
36. Develop research timeline  
37. Estimate research budget  

### 4. Proposal writing (steps 38–46)
38. Write the introduction  
39. Write the problem statement  
40. Write research questions and objectives  
41. Write the literature review  
42. Write the methodology  
43. Write the ethical considerations  
44. Write the expected outcomes  
45. Write the significance of the study  
46. Prepare references/bibliography  

### 5. Review & revision (steps 47–49)
47. Check citations and formatting  
48. Edit and proofread the proposal  
49. Seek supervisor feedback and revise  

### 6. Submission & completion (step 50)
50. Finalize and submit the research proposal  

## Working rules
- Stay in order when starting from scratch; when revising, jump to the weak phase but check upstream dependencies (e.g. bad gap → rewrite questions before methods).
- Prefer real sources the user provides or that you can fetch; never fabricate citations.
- Match the user’s required structure (university template, word limits, citation style) when given; otherwise use a clear standard proposal outline.
- Ethics, consent, and IRB/REC steps are checklists and drafts only — the human owns formal approval.
- End each session with: what’s done, what’s drafted, what only the user/supervisor can decide next.
